# EXP040 methods audit

The frozen direction is damaging-matrix `NF1 (4763)` status to `LAMTOR1
(55004)` dependency in the DepMap 23Q4 naive CRISPR endpoint. Selection used
only frozen input hashes, QC and model metadata, the NF1 status column, the
exact LAMTOR1 endpoint header, literature metadata, and seeded synthetic
planning simulations. No LAMTOR1 score row or endpoint value was parsed.

The implementation must bind the NF1 status rule, exact endpoint, source
families, canonical roster, planning powers, seeds, gates, and claim boundary
before endpoint access. It must write a pre-endpoint receipt before loading
LAMTOR1 values and stop at T0 on coverage, identity, domain, or design drift.

The source study supports an NF1-deficient/LAMTOR1-mTOR dependency in a
CRISPR-coupled interaction analysis. EXP040 tests only transport of that
direction to a frozen source-specific genetic dependency proxy; it cannot
support RAS activity, NF1 protein loss, pharmacologic mTOR/LAMTOR1 claims,
causal mechanism, treatment, or clinical claims.
