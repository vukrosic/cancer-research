## Decision

The program begins with claim-level dependency stability. Generic cross-screen
agreement is not novel, so it is used only as an engineering gate. Novelty can arise
later from a narrowly predeclared subgroup or paralog-loss claim that passes held-out
screen evaluation and is absent from targeted prior-art sources.

## Rejected framing

“Use AI to discover a cure” is neither falsifiable nor supported by public cell-line
data. The repository instead asks a bounded decision question: which hypotheses are
reliable enough to justify the next experimental dollar?
